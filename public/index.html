Газарзүйн солбилцолтой өгөгдөл унших, нэгтгэх, онлайн газрын зургаас татах, рельефийн шинжилгээ (хаялбар, гольдрол) хийх, форматаар хөрвүүлэх API. Бүх хүсэлт Authorization: Bearer <JWT> толгойтой байх ёстой. Sandbox сервер нь энэ spec доторх жишээ хариуг буцаадаг mock тул "Try it out"-ыг бодит өгөгдөлгүйгээр турших боломжтой.

Layers

Давхарга импорт ба формат хөрвүүлэлт (arc42 B1)

WMS

Онлайн газрын зургийн клиент (arc42 B4)

Онлайн WMS/WMTS үйлчилгээнээс боломжтой давхаргуудыг жагсаах (FR-06)

GET хүсэлт тул requestBody байхгүй (RFC 9110); хүсэлтийн жишээг bbox query параметрийн жишээгээр өгсөн.

Authorizations:
BearerAuth
query Parameters
bbox
required
string
Examples:
  • bbox=106.8,47.9,106.95,47.95 - Улаанбаатар хотын төв

minLon,minLat,maxLon,maxLat (WGS84)

Responses

Production server

https://api.geodesk.mn/v1/wms/layers

Sandbox mock (GitHub Pages, spec-ийн жишээ хариуг буцаана)

/./mock/geodesk/v1/wms/layers

Request samples

  • Python (requests)
import os
import requests

BASE_URL = "https://api.geodesk.mn/v1"
auth_header = {"Authorization": f"Bearer {os.environ['GEODESK_API_TOKEN']}"}

# Улаанбаатар хотын төвийг хамарсан WMS давхаргуудыг жагсаана
wms_response = requests.get(
    f"{BASE_URL}/wms/layers",
    headers=auth_header,
    params={"bbox": "106.8,47.9,106.95,47.95"},
)

wms_response.raise_for_status()
for wms_layer in wms_response.json():
    print(wms_layer["layer_id"], wms_layer["crs"])  # wms_satellite_2026 EPSG:3857

Terrain

Рельефийн шинжилгээ (arc42 B5)

DEM өгөгдлөөс хаялбарын шугам тооцоолох (FR-09)

50MB хүртэлх DEM файлыг 8 секундын дотор боловсруулж, заасан интервалтай хаялбарын шугам үүсгэнэ (±0.5м нарийвчлал). 200MB-аас том DEM-ийг 413 кодоор татгалзана.

Authorizations:
BearerAuth
Request Body schema: application/json
required
dem_layer_id
required
string
interval_m
required
number >= 0.5
